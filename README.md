## 🚀 What I've Built (AI & LLM Projects)

| # | Project | What it covers |
|---|---------|----------------|
| 1 | 💬 **LLM Chatbot with Memory** | Chatbot connected to an LLM with conversation-history injection, long-chat summarization, **token-by-token streaming**, token counting and token-limit enforcement |
| 2 | 🏷️ **Document Classification & Sentiment Analysis** | Zero-shot document classification with **Natural Language Inference (NLI)**, sentiment analysis, and working with **HuggingFace** models |
| 3 | 🔎 **Semantic Search** | Embedding-based semantic search engine: generating, storing and comparing embeddings |
| 4 | 🏥 **Medical RAG System** | End-to-end **Retrieval-Augmented Generation** pipeline over medical information, built with **LangChain** |
| 5 | 🌐 **Tool-Using AI Agent** | Agent that calls tools, searches the internet and gathers information to answer questions |
| 6 | 🧾 **Structured LLM Output** | Controlling LLM output format with **JSON / structured output** for reliable downstream use |
| 7 | 🗂️ **Prompt & Memory Management** | Reusable **Prompt Templates**, **Checkpointer**-based memory, and persisting chat history in a **database** |
| 8 | ✍️ **Writer–Reviewer Agents (LangGraph)** | Two cooperating agents: one writes an article, the other evaluates it, forming an **automatic generate → evaluate loop** |
| 9 | 🧭 **Multi-Agent System (Supervisor)** | **Supervisor-pattern** multi-agent system that routes tasks to specialized agents |
